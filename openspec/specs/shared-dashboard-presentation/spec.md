# shared-dashboard-presentation Specification

## Purpose

2次元および3次元ダッシュボード全体で共有される NEJM / Nature Medical テーマ CSS、DataTables 辞書、および数理用語集の共通基盤を提供し、プレゼンテーション層の一元管理と Zero-External-Asset 原則を両立する。

## Requirements

### Requirement: 希少確率の表示精度とETI水準表記を整合させる

ダッシュボード表示は、条件付き割合・群間差などの事後要約において、小さい正の確率を固定小数でゼロへ潰さず有効桁で表示し、数値表の列名および図タイトルは指定された ETI 区間水準（例: 90% ETI, 95% ETI）と厳密に一致しなければならない（MUST）。プレゼンテーション層で数値を再計算・再丸めしてはならない（MUST NOT）。

#### Scenario: 90%と95%のETIを表示する

- **WHEN** 区間水準0.90または0.95でダッシュボードを生成する
- **THEN** 見出し・図・数値表・用語集が同じ水準を示し、小さい非ゼロ確率は有効桁で表示される
- **AND** 固定された「95%CI」表記を用いず、設定水準に応じた「XX% ETI」を表示する

### Requirement: 共通テーマ CSS をインライン注入できる

ダッシュボードレンダラーは、`.agents/shared/dashboard_theme.css` に定義された NEJM / Nature Medical 調の共通スタイル（1px 枠線、`#F6F8FB` 背景、`#1F4D7A` アクセント、px 絶対指定フォント）を、単一 HTML の内部にインライン `<style>` として注入しなければならない（MUST）。

#### Scenario: 2次元ダッシュボードで共通テーマを読み込む

- **WHEN** 2次元カテゴリカル分析のダッシュボードをレンダリングする
- **THEN** `.agents/shared/dashboard_theme.css` のスタイルが `<style>` タグ内に完全にインライン展開され、外部通信なしで同一の学術スタイルが適用される

#### Scenario: 3次元ダッシュボードで共通テーマを読み込む

- **WHEN** 3次元エビデンス分析のダッシュボードをレンダリングする
- **THEN** 同一の `.agents/shared/dashboard_theme.css` がインライン展開され、2次元と同一のデザイントークンで描画される

### Requirement: DataTables 日本語辞書を共通基盤からロードできる

各ダッシュボードテンプレートは、`.agents/shared/` に配備された完全インライン日本語辞書（CDN 参照ゼロ）を共通関数またはオブジェクトから取得して DataTables に設定しなければならない（MUST）。

#### Scenario: 外部 ja.json を要求せずに日本語テーブルを表示する

- **WHEN** ネットワークが遮断された環境でダッシュボード内のテーブルを表示する
- **THEN** ページネーションや検索ボックス、表示件数切り替えが日本語で正常に表示され、外部 CDN リクエストが 0 件である

### Requirement: 完全自己完結型オフライン契約を維持する

共通資産の読み込みにおいて、OS ローカル絶対パス（`/Users/`, `/home/` 等）や外部 URL（`https?://`, `//`）を生成 HTML に残留させてはならない（MUST）。

#### Scenario: 生成 HTML の静的スキャンを実施する

- **WHEN** 共有基盤から生成された 2次元および 3次元 HTML に対して静的正規表現スキャンを実行する
- **THEN** 外部リソース参照およびローカル絶対パス参照が 0 件として検出される

### Requirement: 共通用語集は次元と実際の解析条件に適合する

共通用語集は `.agents/shared/dashboard_glossary.R` に定義し、利用側から渡された次元、基準モデル、事前分布、変数名、分子分母、区間水準、ゼロセルと候補判定の規約に適合する説明を生成しなければならない（MUST）。計算値を用語集側で再計算・変更してはならない（MUST NOT）。不明な条件は未確認として表示しなければならない（MUST）。

#### Scenario: 移行前の主事前の異なる2次元と3次元を表示する

- **WHEN** 2次元結果と移行前の3次元条件付き割合をそれぞれ表示する
- **THEN** 2次元主事前はDirichlet(0.5,…,0.5)、3次元はDirichlet(1,…,1)として説明され、3次元をJeffreysと誤表示しない
- **AND** 既存結果を表示時に再計算せず、3次元の応答・比較・層別・分子分母・区間水準は当該解析設定に一致する

#### Scenario: モデル固有項目と診断規約を分離して表示する

- **WHEN** 2次元独立モデルと3次元の基準モデル別診断を表示する
- **THEN** M1〜M9/BICの説明は3次元に限定し、2次元のレバレッジ閉形式を3次元へ流用しない
- **AND** 3次元ゼロセルのlog(0.5/E)は補正値として示し、−∞という2次元の非有限状態と混同しない
- **AND** 現行3次元候補式にN閾値が入っていない事実と2次元のN≥2000条件を区別し、FWER/FDR保証を主張しない

### Requirement: 数学的定義と解釈上の限界を正しく表示する

用語説明はdesign.md決定4に従い、事後要約・予測・基準モデル・漸近条件を区別しなければならない（MUST）。誤った等式、因果解釈、平滑化や近似精度の無条件保証を共通資産へ転記してはならない（MUST NOT）。

#### Scenario: レバレッジとスコアを確認する

- **WHEN** 非退化な2次元独立モデルの用語を表示する
- **THEN** h_ij=p_i+ + p_+j − p_i+ p_+j、T_score=z²を表示し、標準正規／χ²近似の適用条件を併記する
- **AND** 度数を同じ構成比でc倍したときのEffect不変・Evidence比例と、一般の標本追加を区別する

#### Scenario: BICの絶対値と定数差を確認する

- **WHEN** 3次元モデル比較のBICを説明する
- **THEN** −2ℓ_hat+p log Nを正本として表示し、G²−df log Nとはモデル共通定数K log N−2ℓ_satだけ異なることを明記する
- **AND** 順位・ΔBICの等価性は同じデータ・支持集合・尤度に限定する

#### Scenario: Jeffreysと等裾区間を説明する

- **WHEN** 事前分布とETIの解説を表示する
- **THEN** Jeffreysの密度は自由座標でsqrt(det I)に比例し、Dirichletの総事前濃度はKαであると説明する
- **AND** ETIはデータ・モデル・事前に条件付けた事後分位区間であり、「真の範囲」や平滑化影響がない保証を主張しない

#### Scenario: 条件付き確率の中央値と予測を区別する

- **WHEN** 条件付き確率の事後中央値・平均・ETIを表示する
- **THEN** 同じ条件の次の1観測の予測確率は対応する条件付き確率パラメータの事後平均であると説明し、中央値とは区別する
- **AND** 中央値／分位点の総和は一般には1に制約されないと説明し、2カテゴリの連続分布などで中央値の和が1となる場合を否定しない
- **AND** 条件付けの方向を因果方向と呼ばない

### Requirement: 共通化後の生成物で構造と意味を検証する

両テンプレートから新規生成したHTMLについて共通資産の反映、用語の意味、正常なHTML要素とオフライン性を検証しなければならない（MUST）。過去fixtureや古い文言の一致のみを根拠に完成としてはならない（MUST NOT）。

#### Scenario: 再生成とアコーディオンの検証

- **WHEN** 2次元および3次元band/cardを検証用に再生成する
- **THEN** レンダリング失敗は終了コード等で検出され、コピー済み旧HTMLで成功扱いしない
- **AND** 用語本文がpre/codeにエスケープされず、実DOM要素として存在し、アコーディオン開閉とオフライン表示の確認結果を記録する
- **AND** リポジトリ外作業ディレクトリでも確認済みrootから資産を解決し、欠落資産は明示的なエラーにする

## 変更理由（Why）

対数線形モデル比較において、モデル名として英語の内部識別子（`cond_indep_BC_given_A` 等）がそのまま出力されており、因子記号（$A, B, C$）と実変数（学科、性別、合否等）の対応や数学的定義（ブラケット表記 $[AB][AC]$、条件付き独立記号 $(B \perp\!\!\!\perp C \mid A)$、ポアソン対数線形モデル式）が欠落している。これにより、読者にモデルの意味が伝わりにくく主観的な印象を与える懸念があり、また候補モデルが「仮定する構造」とBIC最小による「相対的採択」の区別が曖昧になりやすいため、早期段階での数学的注記の常設と客観的提示への厳密化が必要である。

## 変更内容（What Changes）

- **因子記号と実変数の明示的マッピング**: 分析変数（`vars`）の順序に基づく因子記号（$A, B, C$）と実変数名の対応関係を Pass 0 から一貫して定義し、結果メタデータおよびダッシュボード上に常時明記する。
- **モデル仕様への数学的メタデータの追加**: 3元表の9候補モデル（M1〜M9）に対し、生成クラス（ブラケット記法 $[AB][AC]$）、実変数展開記法（例: $[\mathrm{Dept},\mathrm{Gender}][\mathrm{Dept},\mathrm{Admit}]$）、条件付き独立の数理記号（例: $(B \perp\!\!\!\perp C \mid A)$）、および日本語の構造解説を定義する。
- **結果 JSON (`evidence_results.json`) の拡張**: `models.summary` に `formula_bracket`, `formula_latex`, `independence_structure`, `description_ja` などの数学的・客観的フィールドを追加出力する。
- **ダッシュボード (`dashboard.Rmd`) の数学的注記強化**: AI サマリーより前に「変数定義・因子記号凡例」を配置し、モデル比較表の直前に期待度数・主効果・交互作用とブラケット記法の解説を配置する。モデル一覧表に「ブラケット表記」「数学的構造（条件付き独立）」列を追加して、どの因子が固定され何が独立であるかを一目で把握可能にする。
- **仮定と実証の厳格な峻別**: AI 考察（Pass 2）およびレポート記述において、「モデルが仮定する条件付き独立性」と「BICによる候補間の相対評価」を峻別し、モデル選択のみを根拠に差別の不存在や完全独立を断定しない記述基準を徹底する。

### 数学的定義と生成元の一貫性

- `analysis_config.json` の `vars` を変数順序の正本とし、記号対応はそこから導出する。対応表を別途手入力させず、`response_var` の指定で順序を暗黙に変更しない。
- モデルの交互作用項を表す共通定義から、実際の適合式と説明用メタデータを生成する。独立した説明辞書を追加するだけでは、式と説明の乖離を防げないため、両者の一致を検証する。
- 結果には記号と実変数の対応、生成クラス、実際の適合式、期待度数の対数線形式、独立性の仮定、日本語説明を保持する。フィールド配置・型・欠損値の意味は後続の設計で確定する。`formula_latex` はブラケット記法と区別し、数式中の添字・期待度数・識別制約も説明する。
- $[AB][C]$ は生成クラス、$(A,B)\perp C$ は独立性として使い分け、`[AB]|[C]` を独立性表記に用いない。ブラケットは最大の交互作用項とその下位項を指定する記法であり、含まれる連関が非ゼロと実証されたことは意味しない。
- M1〜M9の対応を次のとおり固定する。M8・M9に条件付き独立を無理に割り当てず、「一般には独立性制約なし」と交互作用の制約を区別して記録する。

| ID | 生成クラス | 仮定・制約 |
| --- | --- | --- |
| M1 | $[A][B][C]$ | 3因子の相互独立 |
| M2 | $[AB][C]$ | $(A,B)\perp C$ |
| M3 | $[AC][B]$ | $(A,C)\perp B$ |
| M4 | $[BC][A]$ | $(B,C)\perp A$ |
| M5 | $[AB][AC]$ | $B\perp C\mid A$ |
| M6 | $[AB][BC]$ | $A\perp C\mid B$ |
| M7 | $[AC][BC]$ | $A\perp B\mid C$ |
| M8 | $[AB][AC][BC]$ | 全2因子交互作用を含み、3因子交互作用を含まない |
| M9 | $[ABC]$ | 飽和モデル。3因子交互作用まで含む |

### 互換性と表示・解釈の境界

- 数式メタデータのない旧JSONも描画可能とする。未保存の数式を確定情報として補完せず、数学的定義が未収録である旨を表示する。変数対応やモデル定義に矛盾がある場合も、推測した説明を出さず理由を示す。
- 同じエンジンが扱う2元表にも、対応する2記号と既存モデル（M1: $[A][B]$、M2: $[AB]$）の定義を適用する。3元表のM2の説明を流用しない。
- `models.summary` と既存の互換用 `model_selection.summary` の整合を維持する。ダッシュボードでは列を明示選択し、追加メタデータの全列表示による肥大化を防ぐ。長い数式・定義は展開欄等で提示する。
- DT表内の数式が実際に表示されることを検証し、未処理のLaTeXを読者に見せない。日本語・空白・記号を含む変数名について、HTML/LaTeX表示のエスケープとモデル式への対応を確認する。
- BICとΔBICの定義・比較方向を提示し、最小BICは候補集合内の相対評価であることを明記する。モデルの絶対的適合、因果、差別の不存在の証明と同一視しない。最良モデルと局所セル診断の基準モデルも区別する。

## Context

See `proposal.md` - Why.
2次元カテゴリカル分析（`vcd-categorical-analysis`）において、NEJM / Nature Medical 調の臨床・学術標準テーマ、確定行パレット（Okabe-Ito 拡張）、統計状態発散色（正負残差）の独立、および Pandoc Raw HTML Block（```` ```{=html} ````）によるコードブロック化崩れの完全排除が確立された。
本設計は、このデザイン体系の仕様を形式知として記録し、3次元対数線形・ベイズ分析正本スキル（`vcd-bayesian-evidence-analysis`）のダッシュボードへ一貫して移植・適用するためのアーキテクチャを定める。

## Goals / Non-Goals

**Goals:**

- **デザイン体系の記録・共有化**: 2-way で確立したカラーパレット、隔離セルの状態分離、3段構成用語集（定義／どこを見るか／誤解しないこと）を共通設計として記録する。
- **3次元ダッシュボードの視覚刷新**: `vcd-bayesian-evidence-analysis` の HTML ダッシュボードテンプレートを、NEJM/Nature Medical 調の端正なレイアウト（1px 細枠線、影なし、背景 `#F6F8FB`、学術ネイビー `#1F4D7A`）へ統一する。
- **因子群・統計状態の視覚分離**: 因子 A・B・C および層別（Dept等）の一貫したカラーマッピングを行い、正負の調整残差（`#0F766E` / `#B45309`）や隔離セル（琥珀色 `#A16207`）と混同させない。
- **3次元数理用語集アコーディオンの実装**: M1〜M9 対数線形モデル、明示式 BIC（`-2 log L + p log N`）、局所 Rao スコア、多項 Dirichlet 事後推論、一次文献（Agresti, Haberman, Rao, etc.）を網羅した HTML5 ネイティブ折りたたみセクションを ````{=html}```` で追加する。
- **Zero-External-Asset 原則の死守**: 外部 CDN、Web フォント、外部 JS、OS ローカル絶対パスを一切含まない完全自己完結型オフライン HTML を維持する。

**Non-Goals:**

- 3次元対数線形モデルの推定エンジン、Poisson GLM、明示式 BIC 計算、および結果 JSON（Interface 3.0）の数値ロジックは変更しない。
- ユーザー設定ファイルやダークテーマの動的切り替え UI は対象外とする。

## Decisions

### 1. 共通デザイントークン（`THEME_TOKENS`）の統一採用

- **決定**: 2-way と同様の決定論的トークン構造を 3-way テンプレートにも導入する。
  - カード背景: `#F6F8FB` / 枠線: `#E2E8F0` / 本文色: `#152238` / 学術アクセント: `#1F4D7A`
  - 因子パレット: 第1水準 `#1F4D7A`（臨床ネイビー）、第2水準 `#9B2945`（バーガンディ）、3水準以上は Okabe-Ito 準拠の 8 色拡張パレット
  - 統計状態色: 正残差 `#0F766E`（Teal）、負残差 `#B45309`（Amber）、隔離セル `#A16207`（琥珀色太枠）
- **理由**: 分割表の次元（2次元 vs 3次元）を問わず、レポート閲覧者が瞬時に同じ認知モデルでエビデンスを読み解けるようにするため。

### 2. Pandoc Raw HTML Block（```` ```{=html} ````）による構文保護

- **決定**: 用語集アコーディオン（`<details class="glossary-accordion">`）の出力には Pandoc Raw HTML Block を使用する。
- **理由**: HTML ブロック内のインデント（4空白以上）を Pandoc が Markdown コードブロックと誤認して `<pre><code>` にエスケープする障害を 100% 確実に防止するため。

### 3. 隔離セルの状態色独立（非要因群化）

- **決定**: 隔離セル（ゼロ度数、低期待度数 $E < 5$、高レバレッジ $h_{ii} \ge 0.80$）は独立した色相を与えず、琥珀色（`#A16207`）の太枠・中空記号・注記で表現する。
- **理由**: 隔離セルを固有の群（第3群など）として着色すると、要因群との混同や臨床的誤認（無効データの臨床群化）を招くため。

### 4. 用語集の「3段解説テンプレート」採用

- **決定**: 各用語に「① 定義・数理モデル」「② どこを見るか」「③ 誤解しないこと（批判的視点）」を固定する。
- **理由**: 専門家向けの数理的厳密さを担保しつつ、非専門家が P 値や残差から誤った因果推論や過大解釈を行うことを防ぐため。

## Risks / Trade-offs

- **[多水準・多因子による視覚過密]** → 3次元データで水準数が多い場合、静的プロットの視認性が低下するリスクがある。
  - *Mitigation*: 既存のモデル別 BIC 表のソート機能および全件表（DataTables）への誘導を活用し、プロット過密時は代表的な断面（最良モデル M5 の層別等）に焦点を当てる。
- **[Zero-External-Asset の回帰]** → テンプレート刷新に伴い、外部フォントや CDN が誤って混入するリスクがある。
  - *Mitigation*: レンダリング後の静的正規表現スキャンテスト（`tests/test_three_way_dashboard.R`）により、外部 URL / 通信プロトコル / ローカル絶対パスを 0 件判定で強制検証する。

## ADDED Requirements

### Requirement: NEJM/Nature Medical調の学術標準デザインと用語集アコーディオンを提供する

ダッシュボードは、NEJM / Nature Medical 調の臨床・学術標準テーマ（カード背景 `#F6F8FB`、枠線 1px `#E2E8F0`、シャドウ排除、学術ネイビー `#1F4D7A`、バーガンディ `#9B2945`）を採用し、因子群の一貫したカラーパレットと統計状態発散色（正残差 `#0F766E` / 負残差 `#B45309` / 隔離セル琥珀色 `#A16207`）を分離して表示しなければならない（MUST）。
また、末尾に 3次元対数線形モデル（M1〜M9）、明示式 BIC、Rao スコア、多項 Dirichlet 事後推論、および学術リファレンスを網羅したネイティブアコーディオン（`<details class="glossary-accordion">`）を設置しなければならない（MUST）。アコーディオン内の HTML は、Pandoc の Markdown インデント誤認（`pre > code` 化）を排除するため、Pandoc Raw HTML Block（` ```{=html} `）を用いてレンダリングしなければならない（MUST）。

#### Scenario: 3次元ダッシュボードを学術テーマで描画する

- **WHEN** 3次元集計表からダッシュボード HTML をレンダリングする
- **THEN** 全カードが細枠線と学術ネイビーアクセントで描画され、因子水準間で一貫したカラーパレットが維持される

#### Scenario: 用語集アコーディオンを開閉する

- **WHEN** 生成された HTML の末尾にある用語集アコーディオンをクリックする
- **THEN** JavaScript 非依存のネイティブ `<details>` としてスムーズに開閉し、内部テキストが `<pre><code>` にエスケープされず整形表示される

## MODIFIED Requirements

### Requirement: 単一HTMLを完全オフラインで利用できる

ダッシュボードは単一HTMLとして生成され、インターネット接続なしで数式、表、タブ、折りたたみ、列ソート、埋め込み図を利用できなければならない（MUST）。閲覧時に外部script、stylesheet、Ajax、フォント資産を取得してはならない（MUST）。対象表示幅はデスクトップとする。静的スキャンにおいて外部通信（`http:`, `https:`, `//`）および OS ローカル絶対パス（`/Users/`, `/home/` 等）の参照数が 0 件でなければならない（MUST）。

#### Scenario: ネットワークを遮断して開く

- **WHEN** 完成HTMLをネットワーク遮断状態のデスクトップブラウザで開く
- **THEN** 数式と全主要セクションが表示され、モデル表のソートとタブ・折りたたみ操作が動作する

#### Scenario: 外部アセットおよびローカルパスの静的スキャンを行う

- **WHEN** 生成された HTML に対して静的正規表現スキャンを実行する
- **THEN** 外部 CDN、Web フォント、外部プロトコル、および OS ローカル絶対パスの参照が 0 件として検出される

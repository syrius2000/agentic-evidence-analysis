# conditional-rate-view Specification Delta

## MODIFIED Requirements

### Requirement: 条件付き割合と事後不確実性を構造化して保存する

結果は表示設定の写し、層別水準、比較水準、観測分子、観測分母、生割合、事後平均、指定水準の事後信用区間、推定状態を保存しなければならない（MUST）。割合差を計算する場合は方向と参照水準を保存しなければならない（MUST）。
また、条件付き割合・群間差・主／感度差の事後推論要約は、固定小数丸めで正の希少確率や区間をゼロへ縮退させない精度（倍精度）で保存しなければならない（MUST）。

#### Scenario: UCBの学部内割合を保存する

- **WHEN** UCBの条件付き割合計算が完了する
- **THEN** 各DeptとGenderについて分子・分母・生割合・事後平均・95%区間を追跡可能な形で保存する

#### Scenario: 大Nで希少な集約率を保存する

- **WHEN** 度数(0,1,30000,40000,50000)の先頭2カテゴリを分子として主α=0.5・感度α=1.0を計算する
- **THEN** JSON往復後も正の事後平均・ETI端点を保持し、実関数の平均・分位点は誘導Beta解析式とMC誤差内で一致する
- **AND** 感度差は保存用に固定小数丸めする前の要約値から計算し、全ゼロ分母のHOLDを維持する

## ADDED Requirements

### Requirement: 3次元主事前を多項Jeffreysへ移行し感度を明示する

新規3次元条件付き割合の主解析は、明示された支持集合上で対称多項 Dirichlet(0.5,…,0.5)（Jeffreys事前）を用い、α=1.0（一様事前）を感度分析として比較・並行算出しなければならない（MUST）。主／感度のα、分布族、支持集合、区間水準を結果と由来情報（provenance）から追跡可能にしなければならない（MUST）。旧成果物を再ラベルして移行済みと扱ってはならない（MUST NOT）。

#### Scenario: 希少セルとゼロ観測を含む新規run

- **WHEN** 有効な支持集合の計数yから主解析と感度解析を生成する
- **THEN** 主解析はDirichlet(y+0.5)、感度解析はDirichlet(y+1.0)を用い、両者の条件付き確率・区間の差を明示する
- **AND** 構造的ゼロには事前質量を割り当てず、層内全ゼロを含め既存の入力／HOLD契約を維持する

#### Scenario: 複数カテゴリをまとめた確率を解釈する

- **WHEN** 分母のd個のセル中m個を分子にまとめる（0<m<d）
- **THEN** 誘導事前はBeta(mα,(d−m)α)と説明し、セルα=0.5を常にBeta(0.5,0.5)と同一視しない
- **AND** 事後はBeta(y_num+mα,y_den−y_num+(d−m)α)に一致することを検証する

#### Scenario: 旧主事前の結果と移行後の結果を区別する

- **WHEN** α=1.0の旧runとα=0.5の新runを参照する
- **THEN** 事前変更による事後要約の差を表示バグと扱わず、旧runを保存し、新runの由来情報と感度結果を記録する
- **AND** Poissonモデル比較および局所診断の計算は変更しない

### Requirement: 3次元事前パラメータを固定契約とする

条件付き割合の対称多項 Dirichlet 事前パラメータは、primary_alpha=0.5、sensitivity_alpha=1.0 に固定されなければならない（MUST）。スキーマおよび入力検証においてその他の値を指定した場合は明示的なエラーとして拒否しなければならない（MUST）。

#### Scenario: 許可されていない事前パラメータを指定する

- **WHEN** primary_alpha に 0.25 や 1.0 などの 0.5 以外の値、または sensitivity_alpha に 1.0 以外の値を指定する
- **THEN** 暗黙に補正せず、明確なバリデーションエラーとして実行を拒否する

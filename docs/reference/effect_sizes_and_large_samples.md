# 効果量体系と大標本Dual-Filter原則の数理

本ドキュメントは、多次元分割表データにおける全体効果量（**Cramér's $V$**、適合度効果量 **Fei $\text{פ}$**）、多次元表の応答変数プロファイル畳み込み、および大標本リアルワールドデータ（RWD）において統計的有意性と実務的意義を峻別する **Dual-Filter 原則** の数理的基盤を詳述する。

---

## 1. 大標本における「P値飽和問題」（The Large-$N$ Curse）

### 1.1 検定統計量とサンプルサイズ $N$ の比例関係
ピアソンカイ二乗検定統計量 $\chi^2$ は、サンプルサイズ $N$ と母集団における乖離係数 $\phi^2$ の積として表現される：

$$\chi^2 = \sum_{i=1}^K \frac{(O_i - E_i)^2}{E_i} = N \sum_{i=1}^K \frac{(p_{O,i} - p_{E,i})^2}{p_{E,i}} = N \cdot \phi^2$$

ここで $p_{O,i} = O_i / N$ は観測割合、$p_{E,i} = E_i / N$ は期待割合である。
もし母集団において真のモデルとの間にごく僅かな乖離（例：$\phi^2 = 0.0001$）しか存在しない場合であっても、サンプルサイズが大きくなると：
- $N = 1,000 \implies \chi^2 = 0.10 \implies P = 0.75$（非有意）
- $N = 100,000 \implies \chi^2 = 10.0 \implies P = 0.0016$（**極めて有意**）
- $N = 1,000,000 \implies \chi^2 = 100.0 \implies P = 1.6 \times 10^{-23}$（**圧倒的に有意**）

### 1.2 P 値の飽和（P-value Saturation）
数万〜数十万件規模の RWD 分析では、P 値は実質的に無意味な微小ノイズに対しても $P \to 0$ へと飽和（張り付き）する。
したがって、**「P値が有意であるか否か」で関連の有無を判断する古典的推論は、大標本下では完全に破綻する**。統計的証拠（有意性）と実務的意義（効果量）を厳格に分離する体系が不可欠となる。

## 2. 全体効果量の数理

### 2.1 2元分割表における Cramér's $V$
行数 $R$、列数 $C$ の 2元クロス表において、Cramér's $V$ はカイ二乗統計量を標本サイズ $N$ と表の最小自由度で正規化した指標（$[0, 1]$）である：

$$V = \sqrt{\frac{\chi^2}{N \cdot \min(R - 1, C - 1)}} = \sqrt{\frac{\phi^2}{\min(R - 1, C - 1)}}$$

#### 解釈基準 (Cohen, 1988)
自由度 $df^* = \min(R - 1, C - 1)$ に応じた効果の目安：

| $df^* = \min(R-1, C-1)$ | 小さい効果 (Small) | 中程度の効果 (Medium) | 大きい効果 (Large) |
| :---: | :---: | :---: | :---: |
| **1**（$2 \times 2$ 表） | $0.10$ | $0.30$ | $0.50$ |
| **2**（$3 \times 3$ 表など） | $0.07$ | $0.21$ | $0.35$ |
| **3**（$4 \times 4$ 表など） | $0.06$ | $0.17$ | $0.29$ |

### 2.2 3元以上多次元表における畳み込み Cramér's $V$
3つ以上の要因 $A, B, \dots$ と指定された応答変数 $Y$（水準数 $C_Y$）を持つ多次元表において、予測要因群の水準の組み合わせを直積プロファイル（Predictor Profile）として 1 次元に畳み込む：

$$\mathrm{Profile} = A \otimes B \otimes \cdots \quad (\text{水準数 } R_{\rm prof})$$

このとき、プロファイル $\times$ 応答変数 $Y$ の $R_{\rm prof} \times C_Y$ 二次元クロス表に対する Cramér's $V$ を算出する：

$$V_{\rm multi} = \sqrt{\frac{\chi^2}{N \cdot \min(R_{\rm prof} - 1, C_Y - 1)}}$$

これにより、要因数が 3 次元以上の複雑なクロス表であっても、「予測要因全体のプロファイルが応答変数 $Y$ の分布をどの程度強力に規定しているか」を単一の標準化効果量として客観評価できる。

### 2.3 適合度検定における最新効果量 Fei ($\text{פ}$)
1 次元の多項適合度検定（Goodness-of-Fit）において、従来の Cohen's $w$ は帰無期待確率 $p_E$ が一様でない場合に上限が 1 を超えてしまう構造的欠陥があった。
Ben-Shachar et al. (2023) により提案された Fei ($\text{פ}$) は、非一様な期待分布に対しても厳密に上限が 1 に規格化された効果量である：

$$\text{פ} = \sqrt{\frac{\chi^2}{N \cdot \left( \frac{1}{\min_i p_{E,i}} - 1 \right)}}$$

## 3. 大標本 Dual-Filter 原則の体系的運用フロー

総度数 $N > 2,000$ の大標本データにおいては、以下の **Dual-Filter（2段階スクリーニング）** を厳格に適用する。

```
                         [ 入力データ (Total N > 2,000) ]
                                        │
                                        ▼
    ┌────────────────────────────────────────────────────────────────────────┐
    │  第 1 フィルタ (Effect 軸による実質的スクリーニング)                   │
    │  ・全体効果量: Cramér's V >= 0.10 (小〜中以上の連関が存在するか?)       │
    │  ・局所効果量: |log(O/E)| >= 0.20 (|O - E| / E >= 22% の乖離があるか?)  │
    └───────────────────────────────────┬────────────────────────────────────┘
                                        │ PASS (実質的乖離あり)
                                        ▼
    ┌────────────────────────────────────────────────────────────────────────┐
    │  第 2 フィルタ (Evidence 軸による統計的ノイズ排除)                     │
    │  ・Raoスコア統計量: T_i^score >= 3.841 (自由度 1 の 5% 境界値)         │
    │  ・局所 P 値: P_i < 0.05                                              │
    └───────────────────────────────────┬────────────────────────────────────┘
                                        │ PASS (標本抽出誤差でないことを確認)
                                        ▼
    ┌────────────────────────────────────────────────────────────────────────┐
    │  第 3 段階 (Stability & Influence 軸による健全性監査)                  │
    │  ・Stability: REGULAR (E >= 5 かつ h < 0.8) を確認                    │
    │  ・QUARANTINED セルは注意・参考値フラグを付与し、Dirichlet 事後信用区間を参照 │
    └────────────────────────────────────────────────────────────────────────┘
```

### 3.1 第 1 フィルタ: Effect 軸（標本規模不変スクリーニング）
- **判定理由**: サンプルサイズ $N$ が 100 倍になっても、$\log(O_i / E_i)$ および Cramér's $V$ の値は微動だにしない（スケール不変性）。
- **スクリーニング基準**:
  1. 全体効果量 $V < 0.10$ の場合：どれほど全体の P 値が微小であっても、「実務的・臨床的に有意な関連構造は存在しない（自明な大標本ノイズ）」と判定し、過剰解釈を抑止する。
  2. セル単位では $|\log(O_i / E_i)| \ge 0.20$（期待比にして約 1.22 倍以上の過剰または 0.82 倍以下の過少）を満たすセルのみを解釈対象の候補として選定する。

### 3.2 第 2 フィルタ: Evidence 軸（標本抽出誤差の排除）
- **判定理由**: 第 1 フィルタで選定されたセルが、小標本領域における単なる「偶然の偏り（サンプリングノイズ）」でないかを、Rao のスコア検定統計量 $T_i^{\rm score} = \frac{r_{P,i}^2}{1 - h_{ii}}$ により確認する。
- **スクリーニング基準**:
  $T_i^{\rm score} \ge 3.841$（$P < 0.05$）または $T_i^{\rm score} \ge 10.83$（$P < 0.001$）を満たすこと。大標本下ではこのフィルタは高確率でクリアされるが、小度数セルや小標本データにおいて誤検出を鉄壁に防ぐ防護壁となる。

### 3.3 第 3 段階: Stability & Influence 監査
- 選択されたセルが過大レバレッジ（$h_{ii} \ge 0.8$）または極小期待値（$E_i < 5$）に該当しないか（`REGULAR` か）を確認する。
- `QUARANTINED` セルの場合は、カイ二乗近似の P 値を鵜呑みにせず、ベイズ Dirichlet 事後推論による等裾 95% 信用区間を参照する。

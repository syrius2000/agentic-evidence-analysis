# 探索的分析の設計と実務ワークフロー

author: Codex (GPT-5)

高度な分析は、複雑な指標を増やすことではなく、問い・分母・モデル・不確実性・意思決定を切り分けることから始めます。

## 1. 現行の推奨順序

1. **Pass 0**: 変数、水準、度数、欠測、標本単位、独立性、構造ゼロ、目的変数、分母を確認する。
2. **構造**: 3次元なら9個の階層対数線形モデルを比較し、全体関連と3次交互作用を分ける。
3. **効果**: `log(O/E)`、割合差、`d/√N`、`ΔG²/N`で実質的なずれを読む。
4. **証拠**: `ΔG²`、条件付きの近似P値、BIC近似、明示事前のBFを別列で読む。
5. **不確実性**: 信用区間、事前感度、期待度数、推定状態、多重性を確認する。
6. **次の分析**: 実用差の閾値、層別、再分類、追加データ、bootstrapや階層モデルの必要性を相談する。

この順序を、単一の「エビデンススコア」や一律の閾値で置き換えません。

## 2. どの方法をいつ使うか

### 3次元の集計表

[3次元カテゴリカル探索の数理](three_way_models.md)を使います。初期版の対象は、非負整数の集計度数、最大512セル、構造ゼロなし、独立性を利用者が仮定できる表です。割合、重み、複数回答、依存観測、構造ゼロは再設計が必要です。

### 2元表の要約

Cramér's Vやオッズ比は、どの2元周辺表または層別表に対する値かを明記します。Vは3元表のセル効果量ではありません。小標本や大きな表では補正方法を検討します。[Bergsma (2013)](https://doi.org/10.1016/j.jkss.2012.10.002)

### アソシエーションルール（ARM）

Liftは

\[
  \operatorname{Lift}(A\to B)=\frac{P(B\mid A)}{P(B)}
\]

で定義され、ルールの条件付き確率が全体確率からどれだけ変わるかを表します。ただしLiftは対数線形モデルの交互作用、統計的証拠、因果効果と同じではありません。多数のルールを探索する場合は、支持度、候補生成規則、多重性、検証用データを保存します。本リポジトリの3次元経路にはARMを統合していません。

### 疎な表・階層モデル

期待度数が小さい表、構造ゼロ、クラスタ依存がある表では、通常のPoisson近似や独立Dirichletの説明を続けず保留します。候補には、構造ゼロを含む対数線形モデル、bootstrap、階層ベイズ、部分プーリングがありますが、事前、識別性、MCMC診断、計算負担、講座での説明可能性を別計画で検証します。

## 3. Top-K表示の扱い

Top-Kは読む量を減らす表示方法であり、分析対象を自動的に限定する方法ではありません。全セルをJSONへ保存し、次をTop-Kの条件に明示します。

- 基準モデルと層
- 効果量または証拠量のどちらで順位付けしたか
- 同順位、欠測、ゼロ、保留の扱い
- 全セル数と表示セル数
- 多重性・選択後推論を保証しないこと

現行HTMLは、基準モデルM1・M7・M8の全セルを保存し、層別ヒートマップと詳細表で確認できるようにしています。

## 4. 大標本と100倍感度実験

大標本ではP値、尤度差、BFが小さな差にも反応します。Nに普遍的な境界を置くのではなく、効果量、信用区間、意思決定の許容差を一緒に読みます。

全度数の100倍は、同じ表を複製した感度実験です。固定モデルの`log(O/E)`、`d/√N`、`ΔG²/N`がほぼ不変で、P値・BF・区間が変わることを示すために使います。これを新しい独立観測の証拠と報告しません。

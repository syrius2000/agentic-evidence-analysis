# カテゴリカルデータ分析の基礎と読み方

created: 2026-09-06 23:49 (JST)
update: 2026-09-06 23:49 (JST)
author: Codex (GPT-5)

この文書は、名義・順序カテゴリの集計表を読むための基礎資料です。3変数の実装仕様は [3次元カテゴリカル探索の数理](three_way_models.md) に分けています。

## 1. まず表と問いを定義する

カテゴリカル分析では、行数、セル数、総度数 `N` は別の量です。集計CSVの1行が1人を表すとは限らず、度数列の合計が標本サイズです。変数、水準、分母、欠測、標本単位、独立性を先に決めます。

観測度数を `O_i`、モデルからの期待度数を `E_i` とします。期待度数の意味は、相互独立、条件付き独立、均一連関など、どの基準モデルを選んだかで変わります。同じセルでも基準モデルが変われば解釈は変わります。

## 2. 残差

Pearson残差は

\[
  r_{P,i} = \frac{O_i-E_i}{\sqrt{E_i}}
\]

です。deviance残差は尤度比逸脱度をセル単位に分解した符号付き量です。Rの `residuals.glm()` はPearson、deviance、responseなど複数の残差を返します。[R `residuals.glm`公式](https://stat.ethz.ch/R-manual/R-devel/library/stats/help/residuals.glm.html)

正の残差は「その基準モデルの期待より観測が多い」、負の残差は「少ない」を意味します。残差の絶対値だけで重要性を決めません。大標本では小さな差でも統計量が大きくなり得るため、`log(O/E)`や正規化した量、分母、近似条件を併記します。

`|r| = 1.96`や`2.58`を全セルへ機械的に適用することも避けます。複数セルを同時に見る多重性、期待度数の小ささ、モデル選択後の解釈を考慮する必要があります。

## 3. Cramér's Vは補助的な2元表効果量

2元表のPearsonカイ二乗統計量を `χ²`、行数を `R`、列数を `C`、総度数を `N` とすると、古典的なCramér's Vは

\[
  V=\sqrt{\frac{\chi^2}{N\min(R-1,C-1)}}
\]

です。これは2つのカテゴリ変数の関連の強さを要約する量であり、3元表の各セルに付ける値ではありません。層別表、周辺表、条件付き表のどれに対するVかを必ず明示します。自由度や表の大きさに依存するため、`0.1/0.3/0.5`を普遍的な判定閾値として採用しません。

有限標本では古典的Vにバイアスが生じ得ます。補正Vを使う場合も、補正方法と対象表を明示します。[Bergsma (2013)](https://doi.org/10.1016/j.jkss.2012.10.002) はCramér's VとTschuprow's Tのバイアス補正を扱っています。

現行の3次元経路はCramér's Vを合否指標として計算しません。必要な場合は2元の要約分析として別に定義し、3次元モデル比較やセル診断と混ぜません。

## 4. Feiと独自の旧Scoreについて

現行の3次元経路はFeiを算出していません。Feiを導入する場合は、適合度問題の帰無確率、推定方法、分母、0〜1への正規化、参照実装を別計画で定義します。未実装の指標を「採用済みの実務閾値」として報告しません。

旧 `r_P^2-k log N` は、Pearson残差平方からペナルティを引いた探索用の独自列です。局所ダミーの再適合による `ΔG²` や厳密BFではありません。現行では監査用にのみ保存し、関連の真偽、実質的重要性、セルBFの判定に用いません。

## 5. P値と実務的な意味

P値は、指定したモデルの下で観測統計量以上の値が得られる上側確率です。P値は効果の大きさ、仮説が真である確率、実務上の重要性を表しません。[ASA声明](https://doi.org/10.1080/00031305.2016.1154108)

現行の3次元経路では、カイ二乗近似を使える条件を満たすときだけ補助的にP値を表示します。小期待度数、構造ゼロ、境界、非収束、階数不足では保留します。P値が極端に小さい場合は、丸めた0ではなく対数P値を保存します。

受講者が実務判断を行うときは、次を分けて説明します。

1. **構造**: どの階層モデルがデータの関連をどこまで説明するか。
2. **証拠**: 尤度差、近似P値、明示した事前によるBFなど、偶然との整合性を測る量。
3. **効果**: `log(O/E)`、割合差、`ΔG²/N`など、差の大きさ。
4. **不確実性**: 信頼区間、信用区間、事前感度、再標本化の安定性。
5. **実務判断**: 費用、リスク、意思決定基準を踏まえた別の判断。

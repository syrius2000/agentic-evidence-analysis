## 方針

利用者指定により、3次元条件付き割合の多項Dirichlet主事前を各セルα=1.0から0.5へ移行する。既存Change [shared-dashboard-theme-assets](../../openspec/changes/shared-dashboard-theme-assets/proposal.md) を継続し、新しいChangeは作らない。詳細タスクは [tasks.md](../../openspec/changes/shared-dashboard-theme-assets/tasks.md) に一本化する。実装担当はGeminiとし、本作業は計画の改訂である。

工程1〜3は表示資産共通化・誤記訂正を同一事前で検証し、工程4で統計的意味の変更を検証する。最終アーカイブは全工程完了後とする。従前の「計算値不変」は表示共通化工程にのみ適用し、主事前移行による事後結果の変化は意図した差として評価する。

## 統計的根拠と限界

Kセルの対称Dirichletでは事後平均は(y_k+α)/(N+Kα)、総事前濃度はKαである。α=0.5はα=1.0より一様中心への平滑化を弱める。大規模RWDでも希少セル・層内情報は少ない場合があるため、主事前0.5と感度1.0を比較する。ただし「大標本ならJeffreysが必ず優れる」「安全性リスクを保守的に評価する」とは主張しない。二項モデルでゼロ件なら、事後平均はJeffreysが0.5/(n+1)、一様事前が1/(n+2)となり、Jeffreysの方が低い。

各セルへの0.5と、任意に集約した有害事象率へのBeta(0.5,0.5)は同義ではない。分母dセル中mセルを集約すると誘導事前はBeta(mα,(d−m)α)。事後はBeta(y_num+mα,y_den−y_num+(d−m)α)。本移行は既存の多項モデルの各セルα変更であり、集約率ごとに独立Betaを新設しない。構造的ゼロとサンプリングゼロを区別し、支持集合とカテゴリ粒度を記録する。

## Gemini向け変更範囲

1. `.agents/skills/vcd-bayesian-evidence-analysis/templates/pass1_compute.R` の `compute_conditional_rate_view()` とその呼出しを棚卸しする。主事前0.5・感度1.0を明示的に渡し、区間水準のalphaと混同しない。群間差など同関数の派生出力も同じ主事前にそろえる。
2. `templates/analysis.R`、関連設定検証・結果契約・由来情報を整備する。結果に分布族、α、主／感度の役割、支持集合の定義とKを保存する。具体的なJSONパス、欠損時挙動、設定ハッシュへの反映は実装前に同Changeのdesignへ確定する。旧JSONの情報不足を現在の既定値で補填しない。
3. 共有用語集と両テンプレートは結果メタデータに従う。2次元は既存の主0.5・感度1.0を維持する。3次元の旧結果は主1.0、新結果は主0.5として区別する。
4. 新しい隔離runで生成し、結果ファイルハッシュ、manifest、handover、解析条件の由来情報を再作成する。過去runを上書きしない。旧結果との相違は主事前変更として記録する。
5. Poisson BIC・モデル選択・局所診断・候補判定・ゼロセル診断補正は変更しない。3次元候補式にN閾値が入っていない点は既知の別論点として保持し、この移行で解消したとしない。

## 受入条件

- 主0.5・感度1.0の両方で同一支持集合・同一入力を使用し、主結果・感度結果・表示のラベルが一致する。
- Beta解析式を使い、条件付き平均と分位点をMC誤差を考慮して検証する。既存テストの期待値を単純に新値へ置換するだけでは合格としない。
- ゼロ観測、1〜数件の希少事象、大Nかつ希少事象、小さい層、全ゼロ層、複数水準の分子集約を検証する。全ゼロ層は既存HOLD／拒否契約を保存する。
- 事後平均・中央値・ETI・群間差の主／感度差を確認する。区間が一律に狭くなる、ゼロ件が安全を示す、リスク推定が保守的になる等を受入条件にしない。
- 表示共通化前後の同一事前の不変性と、事前変更前後の意図した差を別に記録する。Poissonモデルと局所診断は不変である。
- 既存契約テストと追加した数学的検証を実行し、両ダッシュボードの生成HTML・オフライン性を確認する。

## 規制資料の位置付け

[FDAの2026年1月ドラフト](https://www.fda.gov/media/190505/download) はV.Aで事前の事前規定と根拠、V.Bでどの無情報事前も普遍的に最優先ではないこと、V.Fで合理的な代替事前による感度分析を述べる。医薬品・生物製剤の臨床試験向けドラフトであり、本RWDダッシュボードのJeffreys採用を包括的に承認する資料ではない。

[CIOMS Xの安全性メタ解析報告](https://cioms.ch/wp-content/uploads/2018/03/FINAL-CIOMS-Meta-Analysis-report-Protected.pdf) ではJeffreysの寄与と頑健性・感度分析への言及を確認した。一方、[CIOMS VI](https://cioms.ch/publications/product/management-of-safety-information-from-clinical-trials-report-of-cioms-working-group-vi/) によるα=0.5の具体的推奨は今回確認できていない。VIの本文は登録を求める公開ページであり、未確認を推奨の不存在とは扱わない。

採用理由は「明示した多項モデルにおけるJeffreys主事前の選択、平滑化の程度、希少セルでの感度評価」と記載する。「FDA／CIOMSが一律に推奨」は記載しない。

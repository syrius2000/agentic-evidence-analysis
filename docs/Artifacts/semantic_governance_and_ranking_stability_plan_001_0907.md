# 現行3次元統計経路の意味論とセル順位安定性の整備計画

update: 2026-09-07 00:08 (JST)
author: Codex (GPT-5)

## 目的

旧 `Evidence Score` を正当化する歴史資料と、現行の3次元実装を同じ正本として読める状態を解消する。現行の `three-way-results-v1` 経路を本リポジトリの新規3次元分析における統計的正本とし、スキルの責務、指標の意味、セル順位の不確実性を追跡可能にする。

## 問題の整理

1. ルートの「カテゴリカルデータ分析の偏り抽出.md」は、`r² − k log N` を実質的なエビデンス判定として記述している。これは現行コードの監査用列という扱いと矛盾する。
2. `vcd-categorical-analysis` と `vcd-bayesian-evidence-analysis` の説明に、3次元分析の入口と責務が重なる箇所がある。
3. `ΔG²/N` が効果量のように読める箇所がある。現行の定義は、基準モデルから拡張モデルへの **1観測あたりの逸脱度改善**、同値な表現ではモデル間のKL差（差分）であり、標準化された効果量ではない。
4. セルの順位は探索的な要約であり、leverageや境界フラグだけでは再標本化安定性を保証しない。順位の再現性を別途評価する必要がある。

## 実施順序

### 第1段階：旧思想の退役と導線の修正

- ルートの旧文書を削除せず、冒頭に `DEPRECATED` と現行正本への導線を追加する。
- 旧 `Reference.md` と旧経路説明は互換性・履歴専用であることを明記し、新規3次元分析への入口から外す。
- `README.md`、`AGENTS.md`、`docs/reference/README.md` から現行経路と履歴経路の境界を確認できるようにする。

### 第2段階：スキル責務の固定

- `vcd-pass0-consultation` は目的・軸・分母・独立性・実用差を固定する入口とする。
- `vcd-categorical-analysis` は名義カテゴリの2次元を主とするプロファイル、残差、全体効果量、既存HTMLの互換保守を担当する。新規の3次元階層モデルの推論本体は担当しない。
- `vcd-bayesian-evidence-analysis` は集計済み3次元表の `three-way-results-v1`、9階層モデル、基準モデル別セル診断、明示事前の割合・差、保留付き日本語考察を担当する。
- `vcd-categorical-reporting` はレガシー報告テンプレートとして隔離し、新規分析には誘導しない。

### 第3段階：指標の意味論を正本化

- `ΔG² = 2(ℓ_1 − ℓ_0)` を入れ子モデルの尤度比改善量と定義する。
- `ΔG²/N` を `1観測あたりの逸脱度改善（per-observation deviance improvement）` と記載する。
- 固定総度数の多項表では、これは基準モデルと拡張モデルのKL乖離の差（`2[D_KL(観測分布||基準) − D_KL(観測分布||拡張)]`）として解釈できる。ただし、Cramér's V等の効果量、セルの確率、セルBFとは同一視しない。
- `log(O/E)`、`d/√N`、`ΔG²/N`、局所 `ΔG²`、BF、信用区間を、差の大きさ・診断・モデル改善・不確実性の別軸として表とナラティブで分離する。

### 第4段階：セルランキング安定性の追加設計

実装前に、次の仕様を計画書とテスト仕様へ落とす。

- ランキング単位を「基準モデル・指標・上位K」に固定し、異なる指標の順位を混ぜない。
- 個票がある場合は標本単位を保ったbootstrap、集計度数だけの場合は明示した多項またはPoisson再標本化を使う。度数を100倍する教材実験を独立再標本化と扱わない。
- 各反復でモデル適合、セル診断、順位を再計算し、セルごとの上位K包含率、順位の中央値・区間、順位相関、適合成功率を保存する。
- 非収束、構造ゼロ、境界、階数不足の反復は失敗理由と有効反復数を分母に記録する。安定性スコアを証拠量や効果量へ合成しない。
- 固定の普遍的合否閾値は置かず、講座・実務の目的に応じた事前設定値を明示する。

## 受入れ基準

- 現行3次元スキルの新規利用者が、旧Evidence Scoreを現行のセル証拠や効果量と誤認しない導線になっている。
- `ΔG²/N` の式、単位、KL差としての意味、非該当な解釈が `docs/reference/` とスキル契約で一致する。
- 2スキルの責務境界を入口文書だけで判断でき、相互に同じ3次元計算を主張しない。
- セル順位安定性は、実装済み・設計中・未評価を成果物で区別できる。
- 既存の歴史的出力を読める互換性は保ちつつ、新規分析の正本から旧思想を除外する。

## 今回の変更範囲

今回のラウンドでは、第1〜3段階の文書とスキル入口を更新し、第4段階は実装仕様と検証計画を残す。bootstrap実装、出力schema変更、既存生成物の再生成は別変更として扱う。

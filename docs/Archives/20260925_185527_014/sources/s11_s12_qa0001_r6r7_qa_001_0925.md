# 6. 新規 Finding 詳細

## QA0001-L01 — 混在型 `cluster_cols` の暗黙文字列化（Low、任意）

- 根拠: `pass0_routing.R:59-63` で `is.list(value)` の場合に `unlist(value)` してから `is.character()` 判定するため、`list("site", 1)` は `c("site","1")` に coerce され受理される（プローブ P1: `NO_ERROR`）。Draft-07 側は `items.type = "string"` で reject する。
- 影響: JSON 経由の設定は `fromJSON` が文字列を返すため通常経路では発生しない。R native 設定でのみ生じ、存在しない列名 `"1"` は後段 `MISSING_DEPENDENCY_STRUCTURE_COLUMNS` で停止するため安全性は保たれる。
- 提案: `unlist` 前に全要素が `is.character` かを検査する。R8 と同様の任意 hardening。

## QA0001-I01 — 本機環境での Python cross-check SKIP

- `Rscript -e 'Sys.which("python3")'` → `/usr/bin/python3`（jsonschema 無し）。`~/.Rprofile:11-22` が PATH を再構成するため、シェルの `python3`（venv、jsonschema 4.26.0）は Rscript から見えない。`PATH=` を前置しても同様。
- 結果としてテスト §9 は `[WARN] … unavailable` + `assert_true(TRUE, …)` の 1 assertion で終了し、合計 133（Python 利用時の 136 と整合）。これは環境制約であり欠陥ではないが、「実 Draft-07 一致」はテストの自動実行だけでは再現されないことを明記する。本レビューでは §4.3 の独立照合で補完した。

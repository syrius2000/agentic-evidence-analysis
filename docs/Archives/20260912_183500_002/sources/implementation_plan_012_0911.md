- `main`は保護して残す。
- `integrate-agy-math-hardening`と`Angigravity`の成果を内容監査したうえで、正式な後継ブランチを1本に集約する。候補名は`phase2-three-way-skill-integration`とする。
- `Angigravity`は名前を後継名へ変更するか、後継ブランチへ統合後に削除する。現行名を正式名称として残さない。
- `agy-branch`はベンチマーク成果を後継ブランチへ取り込む必要があるか確認し、不要なら履歴をリモートタグまたはアーカイブ記録で参照可能にして削除する。
- `cursor/setup-r-environment-9755`はセットアップコミットが`main`または後継ブランチに含まれるか確認し、含まれていればリモートブランチを削除する。未反映なら先にcherry-pick相当の内容監査を行う。

## 実施段階

### 1. 保全と差分台帳

- 全5ブランチの先頭SHA、Worktree、追跡先、未統合コミット一覧を保存する。
- 各固有コミットについて、コード、テスト、文書、生成物、環境設定に分類する。
- `main`、リモート、既存Worktreeに未コミット差分がないことを再確認する。

### 2. 後継ブランチの作成

- `main`を直接変更せず、正式後継名のブランチを作成する。
- Phase 1の`integrate-agy-math-hardening`とPhase 2の`Angigravity`を、コミット単位または選択的な内容統合で取り込む。
- `agy-branch`とR環境セットアップの変更は、統計機能へ不要な履歴や生成物を持ち込まないよう採否を明示する。
- 衝突解消では、現在の数理契約、Pass 0、run scope、sealed、path securityを優先する。

### 3. 統合後検証

- 3次元数理ハードニング、Pass 0、run scope、可搬性、既存スモークテストを実行する。
- `main`との差分に、意図しない削除、絶対パス、raw生成ログ、sealed成果物の改変がないことを確認する。
- 後継ブランチのWorktreeをcleanにし、リモートへpushしてSHAを照合する。

### 4. 旧参照の整理

- Angigravity Worktreeを削除する。clean確認済みであるため、原則として復元可能な通常のWorktree削除を使う。
- 旧ローカルブランチは、後継ブランチへの統合確認後に`-d`相当の安全削除を行う。未統合の場合は強制削除しない。
- 旧リモートブランチは、後継ブランチのpushと固有コミットの保存を確認した後に個別削除する。
- 削除したブランチ名、先頭SHA、代替参照先を整理Artifactへ記録する。

## 削除しないもの

- `main`および`origin/main`
- 統合前の固有コミットを指すブランチ参照
- 未確認のベンチマーク結果、R環境設定、sealed run、ユーザーの未コミット差分
- リモートブランチを残すかどうか未確定の状態での強制削除

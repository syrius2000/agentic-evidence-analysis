# Titanic 3次元探索テストの考察

## 結論

`Class × Sex × Survived`の集計表では、相互独立モデルM1よりも2因子関連を許すモデル群の適合が大きく改善し、全ての3因子関連を含むM8ではM1からの逸脱度改善が `ΔG² = 953.1451`、`ΔG²/N = 0.4331` でした。ここで `ΔG²/N` は1観測あたりの逸脱度改善であり、標準化効果量やセルBFではありません。

M8から飽和モデルM9へ追加される3次交互作用の改善は `ΔG² = 65.1798` ですが、実装はこの比較の漸近推論を保留しています。したがって、M8を自動的な唯一の正解とはせず、2因子関連で説明できない残差と、実務上許容できる差を追加確認します。

## データと設計

- 入力は32行の集計表で、`Freq`の総度数は2,201です。
- Pass 0で4変数から `Class`、`Sex`、`Survived`を選び、`Age`は同じ3元セル内で合算しました。
- `Survived`を条件付き割合の応答変数としました。
- 欠測はなく、集約後の16セルに標本ゼロはありません。ただし、教材CSVだけから標本設計・独立性・構造ゼロを完全には検証できません。

## 全体構造

9つの階層対数線形モデルを比較しました。M1（相互独立）の逸脱度は `1018.3249`、M8（3次交互作用なしで全ての2因子関連を含む）の逸脱度は `65.1798`、M9（飽和）の逸脱度は数値上ほぼ0です。

M1からM8への改善は大きい一方、M8からM9の比較は疎な期待度数や非正則性により近似状態が保留です。BIC差の近似log BFを厳密BFやモデル事後確率と同一視せず、モデル選択を自動確定しません。

## 条件付き生存割合とセル診断

1等・女性の生存割合は事後平均 `0.9720`、点ごとの95%信用区間は `0.9397`〜`0.9922`でした。これはこの条件群内の割合の不確実性を示すもので、因果効果や全体の生存確率ではありません。

M1を基準にしたセル診断では、1等・女性・生存の観測度数141に対し期待度数は約22.42で、`log(O/E)=1.839`でした。反対に、乗組員・女性・非生存は観測3、期待約127.93、`log(O/E)=-3.753`でした。これらはM1からの局所的なずれを示しますが、探索的なセル順位であり、セル単位の確証的判定ではありません。

leverageはモデル行列上の診断値です。セルの影響度や再標本化安定性とは異なり、今回のHTMLでも安定性は未評価として表示します。

## ベイズ推定と限界

飽和多項モデルのDirichlet事前（総集中度1）で、独立モデル対飽和モデルの厳密log BFは `466.9639`でした。これは指定した事前に依存する表全体の比較であり、セルBFではありません。事前感度、点ごとの区間、多重性未調整の条件付き差を併記します。

本テストはスキルとダッシュボードの動作確認です。観察データの関連を因果関係と解釈せず、実務利用では標本単位、抽出条件、依存性、欠測・構造ゼロ、実用上の許容差をPass 0で再確認してください。セル順位の再標本化安定性は現行初版では未実装です。
